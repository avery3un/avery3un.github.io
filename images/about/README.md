# images/about

文件名请全部用小写（GitHub Pages 区分大小写，BTS.jpg 和 bts.jpg 算两个不同的文件）。

- `main.jpg`：工作证上的证件照（会自动裁成竖版 3:4，以人物为中心）
- 拍立得照片（会自动裁成正方形）：`bts.jpg` `climb.jpg` `cook.jpg` `travel.jpg` `nature.jpg` `craft.jpg` `kid.jpg`（小时候）

以下手写图片都是可选的，放进来就会自动替换占位文字（建议透明背景 PNG）：
- 拍立得标签（放在 images/handwriting/）：`label-bts.png` `label-climb.png` `label-cook.png` `label-travel.png` `label-nature.png` `label-craft.png` `label-kid.png`
- 工作证签名：`images/handwriting/signature.png`
- 工作证右下角头像：`avatar.png`（现在是 🎬）
- 绿色便签内容：`note.png`
